# -L-NEA-DE-COMANDO-PARA-LEVANTAR-SERVICIOS-EN-RED
Configurar diferentes servicios de red mediante el uso de la línea de comandos en el sistema operativo CentOS Stream. Se utilizan comandos de Linux para instalar, iniciar, detener y administrar servicios como SSH, FTP, HTTP y NTP, verificando su correcto funcionamiento y aplicando medidas de seguridad mediante Firewalld y SELinux.
